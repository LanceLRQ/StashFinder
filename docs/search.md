# 搜索与重复候选

简体中文 | [English](search.en.md)

搜索读取已登记分区的本地索引，默认包含在线和离线记录，历史记录须显式勾选。结果不表示源文件当前可打开。搜索不会读取内容，也不会更改源文件。

## 常用查询

在应用内按 F1，或选择「帮助 → 搜索语法」，可离线查看常用查询示例。

| 输入 | 含义 |
|---|---|
| `aaa bbb` | 两个子串都出现，顺序不限，默认可以分别出现在目录和文件名中 |
| `"aaa bbb"` | 连续短语 |
| `a\|b c` | `(a OR b) AND c`；OR 优先于 AND |
| `<a b>\|c` | 使用 `< >` 明确分组 |
| `!backup` | 排除含 backup 的记录 |
| `*.mkv`、`photo-?.jpg` | 不带路径的通配符匹配文件名；带路径则匹配卷内路径 |
| `path:projects` | 强制匹配路径 |
| `parent:"projects\demo"` | 指定父目录的直接子项 |
| `ancestor:projects` | 指定目录及其子目录中的条目，按目录边界匹配 |
| `name:report` | 强制匹配名称 |
| `file:`、`folder:` | 文件或文件夹 |
| `ext:mkv;mp4` | 多个扩展名按 OR 组合 |
| `size:>=1GiB`、`size:0..1MiB` | 精确大小比较或闭区间；未知大小和目录不满足大小条件 |
| `dm:today`、`dc:2026-11-01..2026-11-05` | 修改／创建日期，使用本地日期边界 |
| `regex:"(?=report).*\.pdf$"` | 局部 PCRE2 正则；包含查询语法字符时加引号 |

`C:\aaa` 只匹配当前挂载在 C: 的在线分区。离线分区使用分区筛选和卷内路径，不使用历史盘符。路径分隔符 `/` 与 `\` 在普通模式下统一处理。默认文本匹配按 Unicode 小写处理；完整单词使用 PCRE2 Unicode 单词边界。

大小支持 B、KB/MB/GB/TB（1000 进制）与 KiB/MiB/GiB/TiB（1024 进制），最多 6 位小数。比较符为 `= > >= < <=`；日期还支持 `today`、`yesterday`、`thisweek`（周一开始）和 `thismonth`。未知时间不满足日期条件。

筛选菜单提供大小写、完整文件名、完整单词、名称开头／末尾、通配符与正则模式。带空格的完整名称应加引号。全局正则模式将整个输入框当作 PCRE2 表达式，图形筛选仍然生效；局部 `regex:` 则可以与外围查询组合。

正则采用 UTF/UCP 模式，单次匹配上限为 100,000 次尝试、128 层深度和 4 MiB 堆预算。编译错误、超限、不支持的函数、无效区间和过深分组均显示错误，不当作零结果。表达式最长 4096 字节，分组／排除最多嵌套 24 层。本工具实现上述兼容子集，未声明支持全部 Everything 函数。

## 文件类型与范围

类型多选按 OR 合并，再与其他条件 AND 组合。「设置 → 文件分类」可新增、编辑、移除扩展名分类；前导点和大小写统一处理，分类名称不能重复，扩展名不接受路径或通配符。分类保存在当前用户配置中，不更改系统文件关联。

「搜索 → 筛选预设」和搜索栏的「筛选器」提供系统类型与个人预设。可以把文件／文件夹、扩展名、大小和创建／修改日期另存为预设，或从「搜索 → 管理筛选预设…」维护。浏览标签选择预设时只筛右侧列表，左侧目录树保持可导航。菜单记住浏览选择，并作为新搜索的默认筛选；每个搜索标签可单独覆盖或清除。关闭高级搜索弹层会丢弃未应用的搜索条件。

活动搜索标签中，Ctrl+I 切换大小写，Ctrl+B 切换完整单词，Ctrl+U 切换路径匹配，Ctrl+R 切换正则。完整单词和正则共享一个匹配模式。

按 Ctrl+D 或选择「书签 → 添加当前搜索…」可保存关键词、范围、匹配选项、文件条件和排序。打开书签会新建搜索标签。限定分区或目录的书签可在该分区离线时查询索引，原分区身份或目录失效时需重新选择范围。

在「书签 → 管理书签…」重命名或移除书签。点「保存」后应用全部修改，点「取消」保留原书签。

浏览页发起搜索时可选择原浏览分区或原文件夹及子目录。还可选择单个分区、仅在线、包含历史记录。目录范围绑定索引中的目录 ID；目录已不存在时明确报错，不通过同名路径猜测。

## 重复候选

| 输入／图形入口 | 分组键 |
|---|---|
| `dupe:`、`dupe:name`／同名 | 完整名称，文件和文件夹分开 |
| `dupesize:`、`sizedupe:`、`dupe:size`／同大小 | 精确字节数，仅文件 |
| `dupe:name;size`／同名且同大小 | 名称和大小共同一致 |
| `dupe:dm`／同修改时间 | 精确保存的 FILETIME |
| `dupe:name;size;dm` | 三个属性共同一致 |

先完成分区、状态、类型、关键词、大小和日期等普通筛选，再在全部匹配项中分组，最后全局排序并分页。多个查重条件合并为组合键；查重指令不能放在 OR、排除或分组内部。未知分组字段排除并计数，真实零字节可正常成组。

至少两个独立文件对象才构成候选组，同一文件的多个硬链接不单独构成重复对象。符合条件的组保留所有匹配路径，并标记硬链接。离线数据仍是历史快照；相同元数据不保证内容相同，不表示可释放的空间。本阶段没有哈希、自动删除或文件操作。

## 大结果列表

搜索完成后，从「文件 → 导出搜索结果…」或按 Ctrl+S 将所选结果或全部匹配保存为 UTF-8 CSV。导出沿用当前结果顺序，支持未加载的结果和离线索引。路径为卷内路径，时间为 UTC，未知字段留空。

列标题和筛选菜单都按完整结果排序，未知数值始终排在已知数值之后。界面只加载视口附近记录，滚动不会创建千万个 DOM 行。Ctrl/Shift 选择可跨分页，Ctrl+A 选择整个查询结果，不只选择可见行。搜索结果右键可在新 Tab 浏览父目录。

改词、应用新条件或关闭搜索标签时，界面会取消被替换的查询并忽略其旧响应。后台保留查询使用的索引快照，索引更新不会改变当前分页中的顺序。分区读取失败单独列出，其余分区仍可查询；查询本身失败与无匹配结果分别显示。

语法参考：[Everything 搜索](https://www.voidtools.com/support/everything/searching/)、[PCRE2 模式](https://www.pcre.org/current/doc/html/pcre2pattern.html)。性能实测见[查询基线](query-performance.md)。
