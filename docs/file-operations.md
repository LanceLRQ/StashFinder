# 文件操作

简体中文 | [English](file-operations.en.md)

目录和搜索列表共用文件操作。索引仍只读；文件操作由普通权限桌面程序交给 Windows 执行，后台服务不接受任意路径写盘命令。

## 操作与快捷键

| 操作 | 方式 |
|---|---|
| 打开文件／浏览目录 | 双击或 Enter；离线目录只能浏览索引 |
| 复制文件 | Ctrl+C，然后在资源管理器或其他接收程序粘贴 |
| 拖出文件 | 从文件行拖出，始终使用复制语义 |
| 剪切 | Ctrl+X；仅发布剪切列表，源文件此时仍在原处 |
| 粘贴 | 在浏览页的当前目录按 Ctrl+V，或右键空白处；搜索页没有粘贴目标 |
| 重命名 | 单项 F2 行内编辑，Enter 提交、Escape 取消；已有名称冲突会拒绝 |
| 删除 | Delete，确认后请求 Windows 回收 |
| 永久删除 | Shift+Delete，显示文件与数量，默认取消 |
| 属性 | 单项在线可打开 Windows 属性；其他选择显示索引元数据 |
| 文字复制 | 右键复制名称／路径，离线和历史记录同样可用 |
| Windows 菜单 | 右键最底部“更多...”，支持单项和同目录多选 |

Ctrl/Shift 多选，Ctrl+A 选择整个目录的直接子项或整个搜索结果，不局限于已加载行。一次操作最多准备 10,000 个选中记录；上限在父子归并之前检查，超量会整体拒绝，不截断。准备完成后，选中文件夹及其子项时，实际文件操作只保留顶层选择；不同路径的硬链接分别处理。输入框和输入法组合期间不执行文件快捷键。

## 可用性与结果

执行前按登记分区、文件系统实例、索引版本和原生文件身份核验实际对象；盘符不作为身份。离线、历史、身份未知、路径被替换或重解析点会阻止真实文件操作。旧扫描索引缺少原生身份时，应先更新索引。纯文字复制不访问源盘；离线路径使用分区自定义名称，不能当成当前可打开路径。

粘贴只允许当前在线的已登记目录。允许显式粘贴 Explorer 等应用剪贴板中的外部实体文件；纯文字、虚拟附件和含糊的移动标志会拒绝。执行权限与资源管理器相同，不自动提权。复制／剪切发布到剪贴板只代表发布成功；拖出“目标已接受”也不能证明目标完成复制。

其他应用接收的是标准 Windows 文件路径剪贴板，后续执行由接收方负责。发布后若源文件、盘符或挂载位置发生变化，请重新复制或剪切，再粘贴。

应用自己执行的粘贴、改名和删除会保留逐项结果，区分完成、失败、跳过和未执行；可取消后续工作，已完成的部分不会自动回滚。关闭窗口时若仍在执行，会提示等待或取消。Windows 的冲突、权限和不可回收提示可能需要用户处理；回收失败不静默重试永久删除。回收站是否可用取决于文件系统、设备及 Windows 设置。

文件变化通过后台正常索引流程反映。自动更新关闭或分区暂停时显示待更新，不直接删改界面记录来假装已同步。浏览位置保持，索引版本变化后清空旧选择，避免选中另一个对象。

基础扫描模式有一项已知限制：极短时间卸载并重挂可能未被设备轮询捕获，旧监控句柄不能立即发现后续变化。旧索引仍可读，当前依靠周期校验（约 15 分钟）或手动重新索引补齐；本批尚未修复即时监控恢复。

## Windows 与长路径边界

NTFS 可进行仅改变大小写的改名。本机 exFAT/FAT32 上，Windows Shell 对此可能返回成功而保持原名称；应用会核对实际拼写并报错，可手动先改成不同名称再改回所需拼写，不自动执行两步改名。

“更多...”使用传统 Shell 菜单，取决于本机扩展，不保证复现 Windows 11 的现代菜单或 Explorer 专属功能。跨目录选择暂不提供此入口。第三方菜单命令由 Windows／扩展执行，应用不伪造其逐项完成报告。

长路径能否操作还取决于接收端、目标路径和关联应用。开发机已观察到 Explorer 复制深层目录时出现“目标路径太长”；这属于未完成的复制，不能根据剪贴板发布或拖放接受状态宣称成功。可以选择内部文件复制到较短目标。软件不改变系统长路径设置，也不绕过 Windows 权限或另建复制引擎。
