# StashFinder

简体中文 | [English](README.en.md)

StashFinder 是面向 Windows 10/11 的个人硬盘文件目录管理与搜索工具。它的目标是统一搜索多块硬盘中的文件，即使硬盘未连接，也能根据本地目录记录找到文件所属分区和路径。

## 状态

目前提供正式桌面外壳、分区登记、NTFS 自动建库与 USN 增量更新、任务管理、离线目录浏览和基础搜索。多个浏览标签页分别保留位置、选择与滚动，搜索使用独立标签页；目录树、属性预览与面包屑可隐藏。支持路径与多关键词匹配、仅文件名和分区筛选；列表读取本地索引快照，暂只读。仅已登记分区参与更新；日志断档会保留旧索引并重建，格式化后的旧记录保留为历史。exFAT/FAT32 和无日志 NTFS 支持扫描与在线变化监控，重连时完整校验；高级搜索及日常安装包尚未提供。开发验证入口保留 M0 文件桥接和合成数据测量。

开发与验证步骤见[开发指南](docs/development.md)，依赖来源见[第三方说明](docs/third-party.md)。

## 开发目标

- 自主登记需要索引的分区，按物理硬盘分组管理；分区可设置自定义名称，盘符变化不创建重复登记。
- 保存文件和目录的名称、路径、大小与时间，统一搜索在线和离线记录；不索引文件内容。
- 对 NTFS 使用快速枚举与 USN 增量更新；对 exFAT/FAT32 使用扫描和变化监控，必要时完整校验。
- 默认包含路径搜索，支持多个关键词、文件类型和扩展名筛选，以及大小、时间和正则条件。
- 在筛选后的全部结果内查找同名、同大小及组合属性的重复候选；不把元数据相同视为内容相同。
- 显示分区容量、剩余空间、在线状态及更新时间；离线数据明确标为历史快照。
- 从在线结果复制文件或以复制方式拖到资源管理器等应用，支持目录库备份与恢复。

## 使用边界

只有用户登记的分区才会进入文件扫描。索引过程不修改用户普通文件；缺少 USN 日志时，创建日志需要单独确认，不自动扩容。

离线结果描述最后保存的状态，不代表文件当前可打开。分区格式化后保留旧目录记录，新文件系统经确认后独立登记。

## 技术路线

采用 Rust 后台服务、Tauri 2 + React + TypeScript 界面和 SQLite 本地存储。安装服务需要管理员授权，日常界面以普通用户权限运行。首版面向 Windows 10/11 x64。
