# StashFinder

简体中文 · [English](README.en.md)

StashFinder 是一个 Windows 硬盘目录工具。比如，你记得存过一段录像，却忘了它在哪块移动硬盘里。只要给那块盘建过索引，就可以先搜到分区和路径，等要打开文件时再接上硬盘。

## 开始使用

需要 Windows 10/11 x64。双击打开 Windows 原生工作区，可在同一窗口使用概览、浏览、搜索和任务标签页。准备好构建环境后，在仓库根目录运行下面的命令。[开发指南](docs/development.md)

```powershell
pnpm install --frozen-lockfile
pnpm package
```

- **便携版**在 `.local/packages/`。将 `StashFinder.exe` 放入可写目录，双击即可登记和管理分区。运行 `StashFinder.exe --quick-search` 或双击包内的 `QuickSearch.cmd` 可以独立搜索。两个入口共用程序旁 `data/` 中的索引。[便携版使用说明](docs/portable.md)
- **安装版**在 `target/release/bundle/nsis/`。运行安装程序，后台默认随应用启动和退出。需要关闭窗口后继续更新索引时，可在安装时选择 Windows 服务模式。

首次使用桌面管理的后台时，选择「启动索引后台」并确认 Windows 的管理员授权。进入「概览 → 登记分区…」，选中要管理的分区，保留「登记后自动建立索引」。建库完成后，可以双击分区打开目录，也可以在概览输入关键词，按 Enter 搜索所有已登记分区。

Ctrl+T 新建浏览标签，Ctrl+Shift+F 新建搜索标签，Ctrl+Tab 切换标签。从「工具 → 任务」查看索引进度和历史，Ctrl+P 打开设置弹层。需要使用网页工作区时，运行 `StashFinder.exe --web-ui`。网页入口使用系统 WebView2 Runtime。

## 搜索和浏览

运行 `StashFinder.exe --browse`，或在快速搜索中选择「浏览 → 已登记分区」，可以按文件夹浏览已保存的索引。离线分区也能浏览，按 Backspace 返回上一级，Ctrl+F 切回搜索。

首次使用也可以直接在这个原生窗口点击「登记分区…」，选中目标分区并点击「登记所选分区」。默认会建立索引，窗口底部显示所选分区的进度。取消自动建索引后，可以再选中已登记分区，手动开始。NTFS 缺少 USN 日志时，点击「仅扫描建索引」即可继续。

从「浏览 → 索引任务」或 `StashFinder.exe --tasks` 打开原生任务列表，查看执行阶段和错误原因。选中排队、执行中或等待接入的任务可以取消，这会暂停该分区的自动更新。分区在线并就绪后，可重试失败、中断或已取消的任务。

安装后，两种后台模式都可以直接从开始菜单打开「StashFinder 快速搜索」。输入关键词即可搜索已登记分区，主界面可以保持关闭。在结果列表中按 Enter 或双击可打开在线项目，Ctrl+Shift+C 可复制在线或离线记录的路径。

搜索默认包含在线和离线的已登记分区。在独立标签页里浏览目录或查看搜索结果，可以切回之前的位置。离线时看到的是上次保存的文件名、路径、大小和时间，已有的缩略图也能查看。打开或操作源文件需要接上源盘。格式化前的旧目录保留为历史记录，可在搜索范围中选查。

- 按名称或路径找文件，或按类型、大小、日期筛选。例如 `*.mkv size:>=1GiB` 查找至少 1 GiB 的 MKV 文件。常用条件可以存为筛选预设，整条搜索也可以加入书签。[搜索语法与示例](docs/search.md)
- 在筛选后的全部结果里找同名、同大小的重复候选。候选按元数据分组，是否是同一份内容需要另行确认。
- 在在线列表中可复制、剪切粘贴、改名或删除，也可以把文件拖到资源管理器进行复制。[文件操作和快捷键](docs/file-operations.md)

## 索引和缩略图

索引只扫描已登记的分区，以只读方式收集文件和目录的元数据。搜索直接读取索引。NTFS 有可用的 USN 日志时会用它增量更新。缺少日志时可选择目录扫描，创建日志需要单独确认。exFAT 和 FAT32 使用目录扫描与变化监控，重新接入时会校验已有记录。

在分区或文件夹上选择「分析文件…」，可以提前生成缩略图。进度和处理总数在「工具 → 任务」中查看。对于在线且有连续 USN 日志索引的 NTFS 分区，也可以用这个入口识别 `.ts`、`.dat` 等文件是否含有视频轨道。这项功能需要 `PATH` 中有支持 `fd:` 的 `ffprobe.exe`。识别结果可用于离线的「视频」筛选。[文件分析与缩略图缓存](docs/system-visuals.md)

## 开发

后台使用 Rust，原生界面使用 Rust 与 Win32，索引保存在本地 SQLite 数据库中。网页工作区使用 Tauri 2、React 和 TypeScript。运行 `pnpm dev` 启动网页开发环境，`pnpm check` 执行自动检查。[开发与验证](docs/development.md) · [查询性能基线](docs/query-performance.md)
